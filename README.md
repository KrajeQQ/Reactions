# Reactions

**A mod that adds dynamic expressions and facial personality to players.**

Reactions is a simple client-side mod that brings player skins to life with customizable, vanilla-friendly facial animations. Your character now reacts to the world around them.

## 🚀 Roadmap (Upcoming)
- Fix major bugs and visual inconsistencies.
- Add more expressions based on player actions.

- Improve compatibility with non-standard/custom skins.

## 📋 Requirements
- **Minecraft:** Java Edition 1.21.1, 1.21.4 - 1.21.8
- **Platforms:** Fabric, NeoForge

## 🛠️ Build
Requires JDK 17+.
```bash
./gradlew build # or gradlew.bat build on Windows
```
